# DAY 16 — Boards, Hero Frames and Locked References

**TIME BUDGET: 5h** — 0h watch · 0.25h read · 4h do (incl. 1h Tool Track) · 0.75h QC (**GATES G2, G3**)

## OUTCOME
An 8–12 frame board that passes the stranger test, locked and hashed references, and start/end
frames for every shot.

## WHY THIS MATTERS
**G2 is the highest-value gate in the course.** Everything generated from tomorrow onward
inherits whatever is wrong here. Weak start frames are the single largest cause of bad shots —
not weak models.

## LEARN
- Hero frames vs board frames (different jobs, different budgets)
- Reference hashing as the mechanical meaning of "locked"
- Deriving end frames from start frames

## READ
`modules/storyboarding.md` §2–§3 — 15 min. Refresh only.

## DO
1. **(60 min) Board all 6–10 shots** with `nano_banana_pro`, carrying locked refs as
   `image_references` on every frame. Fast, cheap, geometry-correct. Ugly is fine.
2. **(30 min) GATE G2 — board QC.** Stranger test: show the boards in order, say nothing, ask
   what happened. Check subject consistency, environment consistency, screen direction, ≥3 shot
   sizes. **Do not proceed on a fail.**
3. **(60 min) Hero frames.** The 2–3 frames that define the look. Slow and expensive here:
   `cinematic_studio_2_5` or `soul_cinematic` at 4k. These set the grade and texture for
   everything else.
4. **(60 min) TOOL TRACK is folded in:** as you produce each reference, register it in the
   Console with its **SHA-256**. Then **test the hashing**: modify a reference file and confirm
   the Console detects it. A hash you have not tested is decoration.
5. **(60 min) Start and end frames for every shot.** Derive each end frame *from* its start
   frame (img2img / `nano_banana_2` inpaint), never independently. Use ComfyUI Workflow B for at
   least one shot's start frame — that satisfies the structural-control requirement.
6. **(30 min) GATE G3 — frame QC.** For each start frame ask: *would I be happy if the video
   looked exactly like this, moving?* If no, fix the frame. **It is 20× cheaper to fix a frame
   than to re-roll a shot.**

## VERIFY — GATES G2 & G3
- [ ] **G2:** stranger describes the story from boards alone, in order, no narration
- [ ] **G2:** subject and environment consistent; screen direction consistent; ≥3 shot sizes
- [ ] **G3:** every shot has a start frame you would accept as a still
- [ ] **G3:** every end frame is derived from its start frame and is compatible with it
- [ ] All references locked, versioned and hashed; hashing tested by modifying a file
- [ ] ≥1 start frame came through ComfyUI Workflow B

## SHIP
`02_boards/final_board/`, `03_refs/` (locked + hashed + `refs.json`),
`05_frames/` (start + end per shot), Console populated with all specs.

## FAILURE CONDITIONS
- **Boards look great, story doesn't read** → you made pretty images again. Redo with the floor
  plan open beside you and the beats written above each frame.
- **An end frame is incompatible with its start frame** → different scale, angle or lighting.
  The model will produce a morph. Re-derive it from the start frame.
- **You are tempted to skip G3 because you are behind** → this is precisely where skipping costs
  most. Every hour saved here costs three tomorrow.

## RECOVERY
If a shot's start frame will not come together after ~6 attempts: change the shot size or angle.
A close-up that resists often works as a medium. This is a directorial decision, and making it
deliberately is a skill.

## STOP RULE
Stop when G2 and G3 both pass. **No generation of video today.** Frames only.
