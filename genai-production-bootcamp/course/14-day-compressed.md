# 14-Day Compressed Version — 76 Hours

**For: 5.5h/day × 14 days ≈ 38h/week.** Same terminal deliverable — a 30–60 second film plus a
recruiting package — reached by cutting depth, not outcomes.

## The three risks of the compressed version — and the mitigations

1. **Day 12 merges two gates into one day.** G1 (story) and G2/G3 (board/frames) normally have a
   night between them, and that night catches problems. **Mitigation:** do the naive-viewer test
   on the beats *before* boarding, not after. If the beats don't read, nothing downstream will.

2. **Day 13 is the single hardest day in either version.** All shots, one day.
   **Mitigation:** every shot must be at rung ≥2 with start *and* end frames authored on Day 12.
   The 6-generation cap becomes a **4-generation cap** — you do not have the time to spend six.
   Abandon faster and re-specify faster.

3. **Day 14 compresses comp, edit, sound, colour and packaging into 5.5 hours.**
   **Mitigation:** the priority order is fixed and non-negotiable —
   **edit → sound → colour → comp → package.** If time runs out, it runs out on comp, not sound.
   Sound buys more Film QC points per minute than comp does, every time.

## Adjusted standards

Compressing the schedule does not mean lowering the gates — it means lowering the *scope*.

| Standard | 21-day | 14-day |
|---|---|---|
| Film length | 30–60s | **30–45s** |
| Shot count | 6–10 | **6–8** |
| Film QC threshold | **≥75/100** | **≥75/100 (unchanged)** |
| Shot QC | PASS required | **PASS required (unchanged)** |
| Generation cap per shot | 6 | **4** |
| Difficult motion shots | ≥2 | **≥2 (unchanged)** |
| Previs-controlled shot | ≥1 | **≥1 (unchanged)** |
| Comfy-controlled shot | ≥1 | **≥1 (unchanged)** |
| Substantial AE composite | ≥1 | **≥1 (unchanged)** |
| Console | CLI + API + UI | **CLI + API + README** |

**The QC thresholds do not move.** A shorter film held to the same standard is a portfolio piece.
A longer film held to a lower standard is not.

## Which version should you actually run?

Run the **21-day** version if you can. The extra 29 hours buy you AE3, the Comfy strength sweep,
the Unreal CV line and — most importantly — **slack**, which is what absorbs the one shot that
fights you for a day. Phase 4 in the 14-day version has no slack at all.

Run the **14-day** version if you have a hard deadline (an application, an interview, a
contract). It gets you to a defensible portfolio, and a defensible portfolio in front of someone
beats a better portfolio two weeks later.
