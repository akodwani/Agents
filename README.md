# Agents

Includes **`jobhunt/`** — a persistent, iterative job-discovery system built for
a candidate whose day job exists to fund an acting career. It crawls public ATS
boards and company careers pages, verifies that postings are still live, and
scores them on a 100-point model where acting compatibility and workload
dominate.

See [`jobhunt/README.md`](jobhunt/README.md) for usage, and `out/` for the
generated reports.
